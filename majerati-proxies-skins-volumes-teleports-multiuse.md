## Ep.4: Player proxy skins and spawning items (R_NpSnUqS2k)
Use the wiki **ItemIDs** page for IDs ([../09-reference-ids-rcon-gamemodes.md](../09-reference-ids-rcon-gamemodes.md)); **skin names are case sensitive** (mostly lowercase).
- **Player proxy** is attached to every player (create/assign it on the GL as in the Ep.3 guide). To set a skin: in the proxy, override **Begin Play** -> **`Switch Has Authority`** (Authority) -> `Delay` -> **`Get Pawn`** (the one under the **Player Proxy -> Pavlov API** category) -> **`Get Player Proxy`** -> **`Set Skin`** (target = that player's proxy; **without the target nothing changes**) with a name e.g. `farmer`.
- **Random skin:** `Random Array Item` over a **Make Array** of names (`farmer`, `clown`, `cop`, `prisoner`).
- **Unique skin per player name:** from the pawn **`Get Pavlov Player Status By Pawn`** -> **Break Pavlov Player Status** -> **Player State** -> **`Get Player Name`** -> compare (**`Equal (String)`**, case-insensitive variant) -> Branch. Break fields include cash, team ID, health, booleans, steam ID. **Do not use Steam ID on Shack/Oculus; use player name.** For a list of players: **`Array Contains Item`** with a **Make Array** (refresh pins so it becomes a string array).
- **Spawn gear:** in the GL override **`On Player Spawned`** (gives player state) -> `Delay` -> **`Set Player Buying Enabled`** (duration seconds, max distance; both 500 in the example; **0/0 disables buying**, then spawn fixed loadouts). Team-based loadouts: **`Switch on Int`** on **Team ID** (team 0 / team 1) plus a **default** fallback in case the team check fails: **`Spawn Item`** with **Make Pavlov Spawn Parameters**: **Player = the player state (always connect this or players spawn with nothing)**, **Item ID** (e.g. `m9`, `1911`; the first heard as "toer REV" **[ASR?]**, probably a revolver ID such as `revolver` or `webley`), tick **In Hand**, or **In Inventory** + inventory slot index (**0 = left side, 1 = right side, 2 = back**), options **With Magazine** and default attachments. **Team ID must be untagged "No Teams"** for teams to work.

## Ep.5: skin boxes, gun boxes, instance-editable variables (Tti273LnaHc)
- **Skin volume:** Blueprint **Actor** class -> Add **Box Collision** (set line thickness for visibility; hide the collider in game) + a **Cube** static mesh scaled **~0.66** to fit; a **translucent material** (Blend Mode **Translucent**, Opacity constant ~0.3-0.5). **Make the cube "Hidden In Game" unchecked** so players see it. In the event graph: right-click the box -> **Add Event -> On Component Begin Overlap** -> `Switch Has Authority` -> `Delay` -> **Other Actor -> Cast To Pawn** -> **`Get Player Proxy`** -> **`Set Player Skin`** (name).
- **Gun volume:** same, but **`Get Pavlov Player Status By Pawn`** -> break -> **`Get Game Logic`** (Spawn Item is a **Game Logic** function) -> **`Spawn Item`** with **Make Pavlov Spawn Parameters** (Player = player state).
- **Color trick:** right-click the material's color **constant -> Convert to Parameter** (`Color`); create **Material Instances** (e.g. red) instead of new materials.
- **Instance Editable variables:** drag the hard-coded value (skin name/item ID) -> **Promote to Variable** -> tick **Instance Editable** -> compile/save; each placed copy now has its own value in Details (e.g. one box gives `farmer`, another `clown`; one gun box a knife, another an `m9`). Text on boxes needs replication (covered "later").

## Ep.9: custom skins, data tables, custom hands (UnKNe8L-P0g)
- Needs a **rigged skeletal mesh** (not covered; Blender + a rigging tool; the video "How to make custom Skins" `hjrBEUrNhV4` uses Auto-Rig Pro, paid). Use `Plugins/CustomMapTools Content/Mannequin/Character/Mesh` (**UE4 mannequin, pre-rigged**) as a ready example: **Migrate** the `Character` folder to your **UGC's Content folder** (must target a "Content" folder; pick the folder **above** the UGC folder as shown), then move into e.g. `Custom Skins`; "don't migrate more than that".
- **Skin table:** right-click -> Miscellaneous -> **Data Table** -> row struct **`Player Skin`** -> name (`tutorial skin table`). **+ Add** row: **Row Name = the skin name** you will use in the engine (memorable, simple); **Player Mesh = the skeletal mesh** (the one in the **correct UGC path**, check the path under the highlighted asset); **Hands** type: Bare hands, NATO gloves, Russian gloves, or **Custom**. Add more rows.
- **Global Info** -> Class Defaults -> **Player Skin Table** = your table (works in skin boxes by row name). Alternative: in Global Info `Event Begin Play` -> **`Add Skin To Skin List`** (name + Make Player Skin: mesh + hands); the author prefers the table (faster).
- **Custom hands:** only if the row's hands = **Custom**; then the **player proxy**'s **`Get Custom Hand`** function (Functions list) runs: input **skin name**, return a **skeletal mesh**; he uses a **`Switch on Name`** on the skin name to return each skin's hand mesh. **If Custom is set but no mesh returned it falls back to bare hands.** He does not recommend this method ("far better ways", not covered).
- **Model scale matters**: wrongly scaled models are giant/tiny and register wrong.
- Skeletal vs static mesh explained (static = not rigged; players are skeletal).

## Ep.7: teleporters, interact boxes, VIP (7kL7k7nwOW8)
- **Basic teleporter:** Blueprint class **TriggerBox** -> `Event Actor Begin Overlap` -> `Switch Has Authority` -> **Other Actor -> Cast To Pawn** (cast fail = nothing, so bullets/props don't teleport) -> **`Teleport`** (destination vector). Hard-coding 0,0,0 sends you under the map.
- **Variable destination:** variable **`ActorToTeleportTo`** (type **Actor**, object reference), **Instance Editable** -> `Get Actor Location` of it -> Teleport. In the map, set it per instance (an empty **Actor** placed in the map is invisible in game: good as a destination; rename it).
- **Make the trigger visible in game:** add a **Cube** (scale ~0.8 to fit the green box) with a translucent material; uncheck **Actor Hidden In Game** on the root; **hide the Collision component in game**; press **G** for game view.
- **Grabbable teleporter (door handle):** Blueprint **Actor** -> add **`Pavlov Interact Box`** to the root (red box). Events: **On Interact Box Client** and **On Interact Box Server** (the box gives **Interaction type** (**Grabbed** or **Trigger**), the **Hand Proxy** of the interacting player, and the **Interact Box** itself). Flow: client event -> `Interaction == Grabbed?` (enum equal) -> Branch -> call **`Interact Box Server`** (target: the box, type Grabbed, pass the **Hand Proxy**; the author's server event is the replicated-to-server step) -> server event: `Hand Proxy -> Get Player Proxy -> Get Pawn -> Teleport` to `Get Actor Location` of an instance-editable actor. Scale the interact box a bit larger than the handle.
- **VIP teleporter:** add **array variable `NamesOfVIP`** (string array; not instance editable) -> after the cast: **`Get Pavlov Player Status By Pawn`** -> break -> **Player State -> `Get Player Name`** -> **`Array Contains`** `NamesOfVIP` -> Branch (true = teleport, false = nothing). Make one blueprint toggleable: **Boolean `SpecialTeleporter`** (instance editable, default false) with a Branch before the name check; per placed instance tick it for the VIP door and point its actor reference at the VIP zone.

## "Spawning Chickens & Making Multi-Use BPs" (t--gr9uJR1o)
- **Use the right parent class:** for triggers create the BP from **`SphereTriggerBase`** (or the trigger base): it **pre-configures overlap events/collision**; making an Actor and bolting on a sphere caused the previous video's problems (sphere must "block" and generate overlaps properly). On the visual sphere (static mesh) remove collision and overlap events; the **collider** does the triggering.
- **Proper chicken spawner:** `Event Actor Begin Overlap` (exists by default in these parents) -> `Switch Has Authority` -> `Delay` -> **Cast To Pawn** -> `Get Pavlov Player Status By Pawn` (**its boolean "is player" output** -> Branch) -> **`Spawn Chicken`** (**target = Pavlov Game Logic**, authority/server-only; get it with **`Get Game Logic`**; turn off context sensitivity if the node is hidden) with **Transform = `Get Actor Transform` (self)**.
- **Multi-use asset:** one trigger BP with a **`Switch on Name`** (string switch; **exact, case-sensitive** match, so keep everything lowercase) with cases like `chicken` (spawn chicken), `skin change` (set player skin from a **Skin** variable), `un alive` (**Apply Damage 9999, damage type knife** to the overlapping pawn). Two **instance-editable variables**: **`What To Do`** (name) and **`Skin`**. Each placed instance picks its behavior. Extra: add **Set Material** per path to color the volume (purple/blue/green) when play starts. `Switch on Int` is another option. Add cases with "Add Element".

## Quick reference: recurring nodes/patterns across all five videos
`Switch Has Authority` -> `Delay` -> `Cast To Pawn` -> `Get Pavlov Player Status By Pawn` -> Break (Player State, Team ID, cash, health, dead...) ; `Get Player Proxy` ; `Set Player Skin` / `Set Skin` ; `Get Game Logic` -> `Spawn Item` / `Spawn Chicken` ; `Teleport` ; instance-editable variables for per-placement config ; collapse reused logic into functions ; **Authority/server-only calls need the authority branch**.
