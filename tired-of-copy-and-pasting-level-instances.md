> Summary: Tired of copy and pasting when attempting to make the same building in diffrent places but then realizing you have to copy and paste it again?

---
First thing you want to do is get a cube then right click it, or select all of the items you want to copy and paste! After your done doing that right click on the selected items, then you want to go to levels and click create level instance as showed!
![image](https://image.modcdn.io/members/1d5a/27784228/profile/screenshot2026-04-30031549.png)

**Then You should see something like this,!**

Insure that the "NewMap" is inside of the ugc folder that you want the building object in. If you do see this name it whatever you want like "Level Instanced cube" ect then press save.
Then double click the Level Instance and open it like you would a normal map.
Then more than likely you will see something like this.

![image](https://image.modcdn.io/members/1d5a/27784228/profile/screenshot2026-04-30032647.png)

If you do see this simply click lit and click unlit so you can see the selected object you put into the level instance. If you did this correctly you should see the objects in the level instance, if this is so you can edit it however you like and it will edit every single level instance you've put ingame!
