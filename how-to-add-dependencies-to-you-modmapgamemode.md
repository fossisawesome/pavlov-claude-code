Navigate to the "My content" tab on the top left of the screen.

![image](https://image.modcdn.io/members/2660/8392937/profile/screenshot2024-09-27195223.png)

Find the mod/map/gamemode to which you want to add a dependency and select 'Manage'.

![image](https://image.modcdn.io/members/2660/8392937/profile/screenshot2024-09-27195342.png)

Select the Dependencies tab.

![image](https://image.modcdn.io/members/2660/8392937/profile/screenshot2024-09-27195608.png)

Add the Dependencies that you want to use and press the "Save" button when you are finished.

![image](https://image.modcdn.io/members/2660/8392937/profile/screenshot2024-09-27195744.png)
