### VIP TELEPORTER

 

in your content folder, create a Blueprint Class, and select Triggerbox, and name it "VipTeleporter" or something like this. Open the Event Graph of the VipTeleporter and create two variables

![image](https://image.modcdn.io/members/a827/46747150/profile/capturadetela2026-03-09220547.png)

In the Variable "Names Of Vip", click on him and in Variable Type select "Array"

![image](https://image.modcdn.io/members/a827/46747150/profile/capturadetela2026-03-10135405.png)

![image](https://image.modcdn.io/members/a827/46747150/profile/capturadetela2026-03-10135556.png)

and in the event graph put this blueprint: https://blueprintue.com/blueprint/cceclnom/

make sure if you create an actor in game to be where the player will teleport

**WARNING!!!
**Make sure you marked "Instance Editable" on the Actor To Teleport To Variable

![image](https://image.modcdn.io/members/a827/46747150/profile/capturadetela2026-03-10141103.png)

Click on that:

![image](https://image.modcdn.io/members/a827/46747150/profile/capturadetela2026-03-10140041.png)
 

And put the players name here: 

![image](https://image.modcdn.io/members/a827/46747150/profile/capturadetela2026-03-10140139.png)

Compile and save it

and drag your VipTeleporter to the Viewport.

 

and put the actor you created here:

![image](https://image.modcdn.io/members/a827/46747150/profile/capturadetela2026-03-10140259.png)

save it and **Done**!!!
