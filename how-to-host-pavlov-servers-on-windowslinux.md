> Summary: How to make a server using Docker Desktop

---
Install Docker Desktop 
[https://www.docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)
(On windows make sure you use WSL not Hyper-V)

 

2. Get a Container image
https://github.com/XavierSJC/pavlov-vr-server
(I use this one but im not sure if the others work or not)

 

3. Paste that into terminal 
(Change the Name and password by using arrow keys)

 

4. Port forwarding 

You must log onto your router if you go to your router it will probably be on the back or bottom you need to port forward 9100, 8177, 7777 IF USING THE DEFAULT PORTS if not using default, port forward the ones you set 

INFO:

.If it says something like change name you need to delete the image and redo it and change the server name 
.If you dont keep docker open the server will shut down
.If you have a VPN like Proton VPN and have premium you can port forward through the VPN so no one can find your IP aka the city/town you live in idrc if you know mine
